Write-up

Motivation

After analyzing the data and cleaning the data along with completing exploratory analysis on the data, we found that having a visualization documenting change over time would be the most effective method in answering the question. Where does warming concentrate by 2100, and how much of it does our emissions path decide? In doing so we wanted to show both temperature and precipitation over time along with predictions based on different emission paths.

Visual encodings

We showed the data as a map of 5° grid cells colored by how much each cell changes, because the question is about where warming concentrates and a map makes that easy to see. We used the Equal Earth projection because it keeps areas the correct size. Other projections like Mercator make the Arctic look much bigger than it is, and the Arctic is where most of the warming happens.

In deciding the color palette, we chose to use a red blue scale for temperature and a brown to blue-green scale for precipitation. This was done so as temperature often utilizes blue for colder measurements with red being hotter measurements. For the precipitation, we chose these contrasting colors to signify blue-green relating closely to rainfall and water with brown being a barren desert. The temperature scale goes from −4 °C to +12 °C with white at 0. We made it uneven because almost every cell warms, and a symmetric scale would have wasted half the colors on cooling that barely happens.

The line chart uses position instead of color so you can read exact values for one place. Solid lines are the selected cell, dashed lines are the global mean, and each scenario keeps the same color everywhere.

Data transformations

We used one model run from CMIP6 (GFDL-ESM4, r1i1p1f1) for historical data and three future scenarios (SSP1-2.6, SSP2-4.5, SSP5-8.5). Each scenario continues the historical run, so the series goes from 1850 to 2014 in the historical run and from 2015 to 2100 in the scenario, which means the 2010s decade mixes both. We linearly interpolated the monthly data onto a 5° grid so the map loads quickly in the browser, then averaged it into annual and then decade means to smooth out year-to-year noise. Every value is shown as change from the 1850–1900 average, the standard pre-industrial baseline. Temperature is in °C and precipitation is percent change. Yearly precipitation change is capped at ±100% before averaging, so a few very dry cells with tiny baselines don't produce extreme percentages; after averaging, values range from −85% to +97%. The color scale stops at ±60% so moderate changes stay visible, and the tooltip still shows the exact number. The global mean in the detail chart is weighted by area (cos latitude) so polar cells aren't overcounted.

Interactions

Each control answers part of our question. The scenario buttons switch between low, middle and high emissions, so you can see how much the emissions path changes the map. The decade slider and play button show warming building up from 1850 to the 2090s, which a single static map can’t show. Clicking a cell opens a line chart of that place under all three scenarios next to the global mean, so you can see whether a region warms faster than the planet as a whole. Hovering shows the exact value and how many times the global mean that cell is. Zoom and pan let you look at smaller regions, and country borders fade in as you zoom so the world view stays uncluttered.

Alternatives

One option was three maps side by side, one per scenario. That makes direct comparison easy, but each map would be too small to read 5° cells. Buttons keep one full-size map, and switching makes the differences jump out because everything else stays in place.

A single line chart of global mean temperature would show that higher emissions mean more warming. But it can’t show where warming concentrates, and it hides how much faster the Arctic warms. We kept that global line as the dashed reference in the detail chart instead.

We could have animated the map automatically, but that makes it hard to stop on a specific decade and compare, so the slider is the main control and the play button is optional. A single-hue color scale would have hidden the few cells that cool, so we used a diverging scale with white at zero.

Development process

The work was split evenly between the three of us during each step of the development process with everyone contributing equally in exploratory data analysis along with the development of the website. It took roughly 15 hours to complete in total between the three of us in developing the visualization. The aspect that definitely took the longest time was implementing the interactive feature on the visualization as it took quite some time to make sure that it was working properly.
